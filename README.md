# Devesh Singh — Portfolio

Recruiter-focused portfolio for Data Analytics and AI/ML positioning.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build

```bash
npm run build
npm start
```

## Update later

Projects, skills, experience and certifications are data-driven in `app/page.js`. Add a new object to the relevant array instead of rewriting the layout.

Profile image: `public/profile.jpg`
