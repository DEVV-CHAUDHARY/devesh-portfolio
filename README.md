# Devesh Singh — Portfolio

Premium recruiter-focused portfolio for Data Analytics and AI/ML positioning.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Build

```bash
npm run build
npm start
```
